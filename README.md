# AMP_Prediction_ColabTool

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/tu_usuario/tu_repositorio/blob/main/AMP_Prediction_ColabTool.ipynb)

## 🧬 Description

**AMP_Prediction_ColabTool** is a free, open-access computational tool designed for predicting the **antimicrobial activity of peptides**. It is developed as part of a research project focused on **Quantitative Structure–Activity Relationship (QSAR)** modeling using machine learning algorithms.

This tool provides both:

- 🧪 **Classification** (Antimicrobial / Non-antimicrobial)  
- 📉 **Regression** (LogMIC estimation)  
across different groups of microorganisms.

## 🚀 Features

- Simple and intuitive interface on Google Colab
- Supports both classification and regression models
- Built with machine learning techniques
- Designed for research and educational use
- No installation required — runs entirely in the cloud

## ▶️ How to Use

Click the **"Open In Colab"** button above to launch the notebook and start using the tool. You can run all cells directly without setting up a local environment.
